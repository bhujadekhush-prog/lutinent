# lutinent

## Shorts Studio

A browser-only Hinglish YouTube Shorts planning desk.

### Use

Open the hosted app or open `index.html` locally. Select an idea, edit its hook/script/caption, choose a date and time, then either:

- **Add to daily queue** — stores a draft in this browser's local storage.
- **Export creator pack** — downloads a JSON brief for your video editor or recording workflow.

### Included

- Six starter ideas with editable hooks and script outlines.
- Caption and hashtag drafts.
- A vertical-cover mockup.
- Local queue and creator-pack export.

### Not connected

This starter does **not** log into YouTube, create/render video or audio, upload/publish videos, read channel analytics, or run while your browser/device is closed. It does not claim to identify live trends or guarantee views. Upload automation needs a separately configured and reviewed Google OAuth application, YouTube API access, a real video asset, and an always-online worker.

Draft text and queue data stay in your browser. Do not paste credentials into this page.
